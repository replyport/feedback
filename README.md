# ReplyPort feedback

Use this repository to report bugs, request features, or suggest improvements to ReplyPort.

**Do not post private email content, credentials, mailbox identifiers, access tokens or other sensitive information.** Check screenshots for private information before attaching them.

For setup problems, describe what step failed and what the UI reported, without including private mail.

[Report an issue](https://github.com/replyport/feedback/issues/new/choose) · [Setup guide](https://replyport.github.io/setup/) · [ReplyPort website](https://replyport.github.io/)

This repository is for feedback only. It does not contain the ReplyPort application source.
